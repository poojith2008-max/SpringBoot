# Habit Tracker (Vanilla JS)

## Description
A DOM-based Habit Tracker application built using HTML, CSS, and Vanilla JavaScript. Users can add habits, mark daily completion, track streaks, and store progress using LocalStorage.

## Problem Statement
Maintaining consistency in daily habits is difficult. This app helps users build habits by tracking daily progress and streaks.

## Features
- Add and delete habits
- Daily habit completion
- Streak tracking
- Progress visualization
- Data persistence using LocalStorage

## DOM Concepts Used
- Dynamic element creation
- Event handling & delegation
- Conditional rendering
- LocalStorage state management

## How to Run
1. Download the project
2. Open `index.html` in any modern browser

## Limitations
- No user accounts
- Daily reset depends on system date
